Bundled fonts for offline JavaFX startup. Original files are not modified.

- Manrope 400/500/600/700/800: https://github.com/googlefonts/manrope/tree/master/fonts/ttf
- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- IBM Plex Mono 400/500: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

SIL Open Font License texts are included beside the fonts. Manrope uses static files so weight selection does not depend on variable-font support. Inter's default instance is Regular. Native rendering and weight selection still require graphical acceptance testing.
