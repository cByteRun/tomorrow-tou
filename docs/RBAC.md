# RBAC — роли и доступ

Основание: [ТЗ](TZ.md), FR-01/FR-16/FR-17 и уточнение U-04 в [REQUIREMENTS.md](REQUIREMENTS.md). Матрица описывает текущую серверную реализацию; распределение остальных прав — решение реализации. `STUFF` из ТЗ и `STAFF` в коде — одна роль сотрудника.

✅ — разрешено в указанной области; ❌ — запрещено. Проверки: `AccessPolicy`, `IdentityService`, `ReportService` и сервисный слой.

| Операция | ADMIN | TEACHER | STUDENT | STUFF / STAFF |
|---|---|---|---|---|
| Вход, свой профиль, выход | ✅ | ✅ | ✅ | ✅ |
| Управление пользователями | ✅ | ❌ | ❌ | ❌ |
| Просмотр студентов | ✅ все | ✅ группы своих занятий | ✅ себя | ❌ |
| Просмотр преподавателей | ✅ все | ✅ себя | ✅ преподаватели своей группы | ✅ все |
| Просмотр групп | ✅ все | ✅ курируемые / своих занятий | ✅ свою | ✅ все, без карточек студентов |
| Просмотр дисциплин | ✅ все | ✅ назначенные | ✅ своей группы | ✅ все |
| Просмотр аудиторий / семестров | ✅ | ✅ | ✅ | ✅ |
| CRUD справочников и назначений | ✅ | ❌ | ❌ | ❌ |
| Просмотр расписания | ✅ все | ✅ свои занятия | ✅ своей группы | ✅ все |
| Изменение / отмена расписания | ✅ | ❌ | ❌ | ❌ |
| Чтение оценок / посещаемости | ✅ все | ✅ своих занятий | ✅ собственные | ❌ |
| Изменение оценок / посещаемости | ✅ | ✅ своих занятий | ❌ | ❌ |
| Dashboard | ✅ все данные | ✅ доступные данные | ✅ доступные данные | ✅ контроль преподавателей |
| XLSX / DOCX | ✅ | ✅ доступные студенты, оценки своих занятий | ✅ собственные данные | ❌ |
| Просмотр проверок преподавателей | ✅ все | ✅ своих занятий через API | ❌ | ✅ все |
| Создание проверки преподавателя | ✅ | ❌ | ❌ | ✅ |
| Изменение / удаление проверки | ✅ все | ❌ | ❌ | ✅ только свои |
| Чтение аудита | ✅ | ❌ | ❌ | ❌ |
| Ручное изменение аудита | ❌ | ❌ | ❌ | ❌ |

Сервер проверяет права независимо от меню. Отдельный экран контроля доступен ADMIN/STAFF; преподаватель может читать проверки своих занятий через API. Собственный профиль не даёт прав управления пользователями.
